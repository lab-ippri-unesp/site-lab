# Modelo: README de perfil da organização

A organização `colabhd` ainda não tem README de perfil (nem repositório
`.github`). Para o texto abaixo aparecer em [github.com/colabhd](https://github.com/colabhd):

1. Crie o repositório **público** `colabhd/.github`.
2. Copie os logos usados abaixo para `profile/` nesse repositório
   (`logo-horizontal.svg`, `logo-horizontal-papel.svg` — estão em `../logos/`).
3. Salve o conteúdo a partir da linha demarcada em `profile/README.md`.
4. Em *Organization settings → Profile*, envie o avatar
   `../logos/png/avatar-github-1024.png`.
