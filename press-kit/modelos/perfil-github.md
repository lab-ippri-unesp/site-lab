# Modelo: README de perfil da organização

Para o texto abaixo aparecer em [github.com/lab-ippri-unesp](https://github.com/lab-ippri-unesp):

1. Crie o repositório **público** `lab-ippri-unesp/.github`.
2. Copie os logos usados abaixo para `profile/` nesse repositório
   (`logo-horizontal-curvas.svg`, `logo-horizontal-branco-curvas.svg` — estão
   em `../logos/`).
3. Salve o conteúdo a partir da linha demarcada em `profile/README.md`.
4. Em *Organization settings → Profile*, envie o avatar
   `../logos/png/marca-1024.png`.
